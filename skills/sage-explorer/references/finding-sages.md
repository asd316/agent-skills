# 寻人：如何找到"见解深厚"的人

选人是整个 skill 质量的决定性环节。名气、头衔、引用量都是代理指标，且经常失真。以下标准直接评估思考质量。

## 洞察深度的判别信号

**正面信号（满足越多越优先）：**

- **原创框架**：提出了自己的分析框架、概念或分类法，且被他人（包括反对者）反复使用。
- **预测或判断的记录**：在时间轴上可验证的判断（对趋势、事件、伪问题的预判），而非事后解释。
- **一手经验或一手材料**：做过这件事本身（实践者），或长期直接接触原始材料（档案、田野、原始数据），而非仅靠综述他人成果。
- **能说清对立观点**：能准确复述并认真回应最强反对意见（steelman），而非稻草人化。
- **结论带条件**：给出观点的适用边界和失效条件，而非万能断言。
- **跨时间一致性中的演化**：核心方法稳定但观点随证据更新，能说出自己错在哪、改过什么。

**负面信号（出现则降权或排除）：**

- 观点可预测：立场永远和其阵营一致，从不需要付出智力代价。
- 只有批评没有建设，或只有断言没有论证链条。
- 影响力主要来自传播技巧（金句、人设、平台）而非内容本身。

## 覆盖策略：保证视角的碰撞

选 3–7 位时按角色配比，避免单一叙事：

1. **奠基者**：该领域绕不开的分析框架的提出者。
2. **当代最强解释者**：把复杂问题讲得最清楚、材料最扎实的人。
3. **异见者 / 少数派**：与主流结论相反但论证质量高的人。
4. **实践者**（若适用）：在真实世界里用该领域的知识做过决策并承担后果的人。
5. **跨界者**（若适用）：从相邻领域带来不同切口的人。

不是每个角色都必须有人；但"异见者"若存在有质量的人选，必须纳入。用户明确说"不一定要正派有名的"——所谓派与名是一种绑定，正统地位既可能识别了真材，也可能只是再生产了圈子。对每一位入选者，如实标注：主流/边缘、公认成就、主要争议。

## 检索策略

按顺序组合使用 web 检索，直到能支撑判别：

1. 领域综述与"该读谁"类讨论（学者推荐、书单、论战脉络），先建立人物候选池。
2. 对候选者逐一查：代表作与核心论点 → 一手文本（著作章节、论文、演讲全文、长访谈）→ 同行与反对者的严肃批评。
3. 对声称的原创贡献和预测，做事实核查（提出时间、当时的证据、后来的验证）。
4. 中文领域注意：知乎/豆瓣/播客/讲座视频里常有体制外的高质量研究者；用"领域 + 争议/论战/批评"等关键词去找被主流叙事压掉的人。

## 输出

选人结束后应能写出（用于报告和知识库）：

- 每位人物：一句话定位 + 核心思考方法（一两句话）+ 代表材料 + 主流/边缘标注与争议。
- 人物之间的关系图：谁继承谁、谁反对谁、在哪个具体问题上对立。
