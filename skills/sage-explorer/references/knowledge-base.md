# 知识库模板与增量维护规则

知识库目录：`knowledge/<领域slug>/<人物slug>/`。slug 用小写字母与连字符（如 `qing-shi/yu-dahua`）。

## 人物档案 `main.md` 模板

```markdown
# <姓名/学派名>

- 定位：<一句话：他是谁，在这个领域里独特在哪>
- 光谱：<主流 / 边缘 / 跨界 / 体制外> · 主要争议：<一句话>
- 收录日期：<YYYY-MM-DD> · 最近更新：<YYYY-MM-DD>

## 核心思想体系
<他的世界观/历史观/方法论的整体结构。用分层要点，保留他本人的关键概念和术语。>

## 思考方法（最重要）
<他是怎么想的：分析框架、切入问题的角度、证据偏好、推理习惯。
每条方法注明：适用于什么问题、他用它得出过什么代表性结论、局限是什么。>

## 代表性论断与论据
<按主题分组。每条论断附论据摘要和出处编号 [S1][S2]，对应 sources.md。>

## 与他人的关系
<继承/反对/互补了谁，在具体什么问题上的分歧点。>

## 评价与批评
<最强的反对意见是什么、他的回应、当前证据更支持哪边。>

## 增量日志
- <YYYY-MM-DD>：<本次新增/修正了什么>
```

## 出处 `sources.md` 模板

```markdown
# <姓名> · 出处
- [S1] 《著作名》章节/页码，版本，检索日期 YYYY-MM-DD
- [S2] 文章/演讲/访谈标题，平台，链接，检索日期
```

规则：一手来源优先；每条进入 `main.md` 的具体论断尽量挂出处编号；失效链接标注"已失效"。

## 领域索引 `_index.md` 模板

```markdown
# <领域> · 智者索引

| 人物/学派 | 一句话定位 | 光谱 | 档案 | 最近更新 |
|---|---|---|---|---|

## 覆盖度评估
<已覆盖哪些视角、明显缺什么视角（如缺实践者、缺异见者）、下次优先补谁。>

## 领域内主要对立轴
<这个领域真正的争论焦点是什么，各派站位。>
```

## 增量维护规则

- **先查后写**：研究任何问题前先 Grep `knowledge/`，命中的人物只补充新材料，不重建档案。
- **就地更新**：修正旧内容时直接改 `main.md` 对应段落，并在增量日志记一笔；不保留过期段落的长篇历史。
- **思考方法优先**：空间不够时，压缩结论与素材，保住"思考方法"和"评价与批评"两节——它们是组织答案时的脊柱。
- **时间标注**：易过时的内容（时事评论、进行中的争论）标注"截至 YYYY 年"。
